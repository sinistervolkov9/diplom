# diplom

## Инструкция по запуску

### 1. Клонирование

Клонируйте проект на свой локальный компьютер

### 2. Установите Docker

Убедитесь, что Docker установлен на вашем устройстве. 
Скачать и установить Docker можно с официального сайта: 
[Docker Installation Guide](https://docs.docker.com/get-docker/).

### 3. Запустите контейнеры

Для запуска всех необходимых сервисов 
(Django, Celery, Redis, PostgreSQL) выполните команду:
docker-compose up -d --build

Эта команда соберет Docker-образы и запустит следующие сервисы:

- **web**: Django веб-сервер;
- **db**: Сервис PostgreSQL для хранения данных;
- **redis**: Redis для очередей задач;
- **celery_worker**: Celery worker для выполнения фоновых задач.

### 4. Примените миграции

Для настройки базы данных и применения миграций выполните:
docker-compose exec web python manage.py migrate

### 5. Создайте суперпользователя

Чтобы создать суперпользователя Django, выполните:
docker-compose exec web python manage.py csu

### 6. Доступ к приложению

Админка Django будет доступна по адресу: [http://localhost:8000/admin](http://localhost:8000/admin).

### 7. Остановка

Чтобы остановить и завершить работу всех запущенных контейнеров, выполните команду:
docker-compose down

### Примечания

- Если у вас возникли проблемы с подключением к Redis, проверьте, 
что Redis работает правильно и доступен по адресу `localhost:6379`.
- Убедитесь, что все зависимости установлены в файле `requirements.txt`.

## Инструкция по использованию / Принцип работы

### 1. Заполнение .env файла:
Сначала заполните .env файл, указав все необходимые параметры, включая размер файла 
(в МБ) для загрузки документов и данные для настройки отправки почты.

### 2. Загрузка документа:
Авторизованные пользователи могут загружать документы в форматах DOC, DOCX или PDF. 
Поддерживаемые форматы и максимальный размер файла заданы в валидаторах. 
При успешной загрузке файла администраторам отправляется уведомление 
по электронной почте.

### 3. Работа администраторов:
Администраторы могут просматривать и управлять загруженными документами 
через панель администратора. 
Они могут быстро одобрить или отклонить документы с помощью специальных действий.

### 4. Уведомления пользователей:
После одобрения или отклонения документа его статус обновляется, и пользователю, 
загрузившему документ, отправляется уведомление на электронную почту 
с текущим статусом его документа.

### 5. Доступ к документам:
Пользователи могут видеть только свои собственные документы, 
которые были одобрены администраторами. Документы, 
находящиеся на рассмотрении или отклоненные, доступны только администраторам.

## Документация по проекту

Документация для API доступна в формате Swagger. 
Вы можете ознакомиться с полным описанием доступных эндпоинтов и их функциональностью, 
перейдя по следующему URL:

Swagger UI: http://localhost:8000/swagger/

## Тестирование 

Проект покрыт тестами, что позволяет удостовериться в корректной работе функционала. 
Уровень покрытия тестами составляет 86%.

Чтобы запустить тесты, выполните следующую команду: 
docker-compose exec web python manage.py test

Эта команда выполнит все тесты проекта, 
и вы увидите отчет о результатах и покрытии тестами.
